# Шаг 3. Источник вопросов (JSON)

На шаге 3 ты делаешь **источник вопросов**: часть, которая загружает методики из файлов и отдаёт их движку. Срок — к показу прототипа **20.10**, на твоих заглушках будем показывать сквозной прогон.

## Про API

**Отдельную связь с ядром делать не надо.** Всё это одна программа на Python, никаких серверов и запросов. Связь — это абстрактный класс `QuestionSource` в `portrait/sources/base.py`, его я закоммичу сам:

```python
class QuestionSource(ABC):
    @abstractmethod
    def load_methods(self) -> list[MethodBlock]:
        """Загружает все методики в порядке справочника METHODS."""
```

Движок вызывает только `source.load_methods()` и получает список методик. Откуда они взялись, движок не знает. Сейчас из JSON, позже из базы данных, которую выдаст преподаватель. Твоя задача — реализация для JSON.

## Что сделать

### 1. Три JSON-файла с заглушками

В `portrait/methods/data/`: `m01.json`, `m02.json`, `m03.json`.

- id и названия настоящие (из `METHODS` в `portrait/core/contracts.py`), вопросы выдуманные, по 3–5 штук.
- Используй разные типы вопросов: `scale`, `choice`, хотя бы один `number`.

Формат:

```json
{
  "method_id": "m01",
  "questions": [
    {"text": "Мне нравится узнавать новое", "type": "scale",
     "options": [{"value": 1, "label": "Не согласен"},
                 {"value": 2, "label": "Затрудняюсь"},
                 {"value": 3, "label": "Согласен"}]}
  ]
}
```

`id` вопроса (`m01_q01`), `method_id` и `order` в файле не пишем, их проставляет загрузчик по порядку.

### 2. `portrait/methods/json_method.py` — класс `JsonMethod(MethodBlock)`

Получает словарь из JSON и превращает его в методику:

- `id` — из `method_id`, `name` — из справочника `METHODS`;
- `get_questions()` — список `Question`, где id, method_id и order проставлены автоматически;
- `process(answers)` — **временный** подсчёт: сумма числовых ответов в одну шкалу «Сумма баллов» со статусом `ok` / `partial` / `no_data`. Настоящий подсчёт по ключам будет позже (шаг 10). Образец — `DemoMethod` в `tests/test_contracts.py`.

### 3. `portrait/sources/json_source.py` — класс `JsonSource(QuestionSource)`

- В конструктор передаётся путь к папке с JSON.
- `load_methods()` читает все `*.json`, создаёт `JsonMethod` и возвращает их **в порядке справочника `METHODS`**.
- Если файл битый, нет нужного поля или `method_id` нет в справочнике, выбрасывается `ValueError` с понятным текстом и **именем файла**: «m02.json: нет поля questions».

### 4. Тесты `tests/test_json_source.py`

- Загружаются 3 методики, в правильном порядке, у вопросов правильные id.
- `process` возвращает `ok`, если всё отвечено, `partial` при пропусках, `no_data`, если ответов нет.
- Битый JSON, файл без `questions` и неизвестный `method_id` дают понятную ошибку. Для таких случаев создавай временную папку через `tempfile.TemporaryDirectory()`.

## Как сдавать

1. Ветка `<имя>/json-source`.
2. Pull request в `main`, я сделаю ревью.
3. Перед PR проверь, что `python -m unittest` проходит.

## Чего делать не надо

Движок, показ вопросов, подсчёт по настоящим ключам — это другие шаги.
