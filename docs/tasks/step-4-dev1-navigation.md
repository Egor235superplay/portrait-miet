# Шаг 4. Движок опроса — показ вопросов и навигация (разработчик 1)

**Срок — 22.10 (чт).**

Движок опроса ведёт пользователя по вопросам всех методик. Каркас готов: [portrait/core/engine.py](../../portrait/core/engine.py), класс `SurveySession`. Конструктор и `finish()` написал я. Твоя часть — методы под заголовком «Разработчик 1»: сейчас в них стоит `raise NotImplementedError`.

## Что сделать

| Метод | Что делает |
|---|---|
| `current_question()` | Текущий вопрос или `None`, если вопросы закончились |
| `is_finished()` | `True`, если текущего вопроса нет (все пройдены) |
| `progress()` | `Progress(number, total, answered)`: номер текущего вопроса с 1, сколько всего, сколько отвечено (пропуски не считаются) |
| `next()` | Перейти к следующему вопросу. Можно, только если на текущий уже ответили или пропустили его |
| `back()` | Вернуться к предыдущему вопросу. Ответ при этом не удаляется |

Подробное поведение каждого метода, включая все ошибки, описано в его docstring в `engine.py`. **Docstring — это и есть задание**, читай его внимательно.

## С чем работаешь

Состояние опроса уже заведено в конструкторе:

- `self._questions` — все вопросы всех методик подряд, в порядке показа;
- `self._answers` — `{id вопроса: Answer}`: ответы и пропуски. Если вопроса здесь нет, на него ещё не отвечали;
- `self._index` — номер текущего вопроса в `self._questions`, с 0. Когда вопросы закончились, он равен `len(self._questions)`.

Новых полей заводить не нужно.

**Ошибки:** при недопустимом действии (вперёд без ответа, назад с первого вопроса, вперёд, когда вопросы кончились) выбрасывай `SessionError` из `portrait/core/errors.py` с понятным текстом на русском. Импорт уже есть.

## Тесты

Тесты уже написаны: класс `NavigationTests` в [tests/test_engine.py](../../tests/test_engine.py). Сейчас они выключены строкой:

```python
@unittest.skip("Разработчик 1: убери эту строку, когда реализуешь навигацию")
```

Когда реализуешь методы, **удали эту строку** и запусти:

```bash
python -m unittest
```

Все тесты должны пройти. Методы `answer()` и `skip()` делает разработчик 2. Чтобы ты не ждал его, тесты записывают ответы напрямую в `self._answers`.

## Как сдавать

1. Ветка `<имя>/engine-navigation`.
2. Меняй **только свои методы** в `engine.py` и строку `@unittest.skip` у своих тестов. Разработчик 2 параллельно работает в этом же файле: если трогать только свои методы, git объединит изменения без конфликтов.
3. Pull request в `main`, я сделаю ревью. Перед PR проверь, что `python -m unittest` проходит.

## Чего делать не надо

Приём ответов (`answer`, `skip`), группировка (`grouped_answers`), вывод в консоль — это другие задачи.
