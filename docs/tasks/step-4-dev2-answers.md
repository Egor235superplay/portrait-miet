# Шаг 4. Движок опроса — приём ответов и группировка (разработчик 2)

**Срок — 22.10 (чт).**

Движок опроса ведёт пользователя по вопросам всех методик. Каркас готов: [portrait/core/engine.py](../../portrait/core/engine.py), класс `SurveySession`. Конструктор и `finish()` написал я. Твоя часть — методы под заголовком «Разработчик 2»: сейчас в них стоит `raise NotImplementedError`.

## Что сделать

| Метод | Что делает |
|---|---|
| `answer(value)` | Проверить ответ, сохранить его и перейти к следующему вопросу |
| `skip()` | Сохранить пропуск (`Answer.skip`) и перейти к следующему вопросу |
| `grouped_answers()` | Вернуть ответы, сгруппированные по методикам: `{id методики: {id вопроса: Answer или None}}` |

Подробное поведение каждого метода, включая все ошибки, описано в его docstring в `engine.py`. **Docstring — это и есть задание**, читай его внимательно.

Главное:

- **`answer`:** проверять ответ через `question.is_valid_value(value)`. Если ответ не подходит, выбросить `InvalidAnswerError` с понятным текстом и перечнем допустимых значений, ничего не сохранять и не двигаться дальше.
- **Повторный ответ.** Если пользователь вернулся назад и ответил заново, старый ответ **заменяется**. Дублей быть не должно.
- **`grouped_answers`:** в словаре должны быть **все** методики опроса и **все** их вопросы. Если пользователь до вопроса не дошёл, значение `None`. Это важно: методики различают «пропустил» (`Answer.skip`) и «не дошёл» (`None`).

## С чем работаешь

Состояние опроса уже заведено в конструкторе:

- `self._methods` — методики в порядке справочника;
- `self._broken` — методики, у которых не удалось получить вопросы. В `grouped_answers` у них пустой словарь `{}`;
- `self._questions` — все вопросы всех методик подряд, в порядке показа. У каждого вопроса есть `method_id`;
- `self._answers` — `{id вопроса: Answer}`, сюда сохраняешь ответы и пропуски;
- `self._index` — номер текущего вопроса в `self._questions`, с 0. После ответа или пропуска увеличь его на 1.

Новых полей заводить не нужно.

**Ошибки:** `InvalidAnswerError` — ответ не подходит к вопросу; `SessionError` — вопросы уже закончились. Оба исключения лежат в `portrait/core/errors.py`, импорт уже есть.

## Тесты

Тесты уже написаны: класс `AnswersTests` в [tests/test_engine.py](../../tests/test_engine.py). Сейчас они выключены строкой:

```python
@unittest.skip("Разработчик 2: убери эту строку, когда реализуешь ответы и группировку")
```

Когда реализуешь методы, **удали эту строку** и запусти:

```bash
python -m unittest
```

Все тесты должны пройти. Два последних теста (`test_full_survey_then_finish`, `test_stop_midway_then_finish`) проверяют весь путь от ответов до результатов методик.

## Как сдавать

1. Ветка `<имя>/engine-answers`.
2. Меняй **только свои методы** в `engine.py` и строку `@unittest.skip` у своих тестов. Разработчик 1 параллельно работает в этом же файле: если трогать только свои методы, git объединит изменения без конфликтов.
3. Pull request в `main`, я сделаю ревью. Перед PR проверь, что `python -m unittest` проходит.

## Чего делать не надо

Навигация (`current_question`, `next`, `back`, `progress`), вывод в консоль, подсчёт баллов — это другие задачи.
