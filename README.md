# Портрет личности

Программный модуль для определения личностных характеристик человека по 20 методикам.
Учебная практика ПМ.01, Колледж ЭИ МИЭТ, 2026.

План работы — [PLAN.md](PLAN.md). Что сделать команде сейчас — [TODO.md](TODO.md). Контракт методики — [docs/contract.md](docs/contract.md).

## Запуск

Нужен Python 3.11 или новее. Сторонние библиотеки не используются.

```bash
python main.py
```

Тесты:

```bash
python -m unittest
```

## Структура

```
portrait/
  core/
    models.py       # модели данных: Question, Answer, MethodResult, Portrait
    contracts.py    # контракт методики MethodBlock и справочник 20 методик
  sources/          # источники вопросов (JSON, позже база данных)
  methods/          # методики и общий подсчёт баллов
    data/           # JSON-файлы методик
tests/              # автотесты (unittest)
docs/               # документация
main.py             # точка входа
```

## Договорённости

- **Python 3.11+, только стандартная библиотека.** Ничего не ставим через pip.
- **Имена** переменных, функций, классов и файлов — на английском. **Комментарии и docstring** — на русском.
- Стиль кода — PEP 8: отступ 4 пробела, `snake_case` для функций и переменных, `CamelCase` для классов.
- Каждая функция и класс — с коротким docstring: что делает, что принимает, что возвращает.
- Код пишем понятно для всей команды: без «хитрых» конструкций, лучше длиннее, но очевиднее.
- **Git:**
  - в `main` напрямую не коммитим;
  - каждая задача — своя ветка: `имя/кратко-о-задаче`, например `ivan/engine-navigation`;
  - изменения попадают в `main` через pull request после ревью основного разработчика;
  - перед pull request запускаем `python -m unittest` — все тесты должны проходить.
- Сообщения коммитов — на русском, в повелительном наклонении: «Добавь проверку ответа», «Исправь подсчёт пропусков».
